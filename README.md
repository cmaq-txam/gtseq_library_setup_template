# gtseq_library_setup_template

## Scripts for setting up spreadsheets for GT-seq library preparation

We use scripts to prepare spreadsheets for our lab team to follow and fill out during preparation of GT-seq libraries.

For each library, we create a directory, and execute the following scripts:

- 01_sample_list: produce the list of samples and associated metadata for the library

- 02_plate_assignments: assign samples to plates for the library preparation

- 03_extraction_book: make a .xlsx file with a plate map for extractions

- 04_lib_prep_book: make a .xlsx file with sheets for each plate to be filled out by lab team, as well as sheets for quant information

- 05_sample_submission_form: make a sample submission form to allow sequence provider (in our case, Genewiz Azenta) demultiplex the library

This repo will be updated as we change our methods.
